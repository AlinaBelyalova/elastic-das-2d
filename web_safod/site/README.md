# SAFOD Deep-DAS event explorer: generated site

This directory is a build product. It is published as-is to the GitHub Pages
repository `AlinaBelyalova/safod-event-explorer`, where this file becomes the
repository README. Keep it free of internal paths.

Do not edit anything here by hand: `index.html`, `app.js`, `style.css`,
`data/*.json`, `data/*.geojson` and `plots/*.webp` are generated by the build
and may be overwritten or deleted by the next one. Edit
`web_safod/templates/` or `web_safod/builder/` in the source project instead.
The build never writes or deletes this README.

Rebuild from the project root with the normal command:

```bash
python -m web_safod.scripts.update_event_explorer
```

In the source project everything in this directory except this README is
gitignored. Build, preview and publishing are described in
`web_safod/README.md` and `web_safod/docs/DEPLOYMENT.md`.
